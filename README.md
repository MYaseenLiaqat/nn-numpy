# NumPy Mini Project — Student Performance Analyzer

A tiny beginner project built from the basic NumPy and Matplotlib operations used.

The project takes a small matrix of student scores and uses NumPy to calculate statistics, perform a weighted score with matrix multiplication, and visualize the results.

## Concepts used

- NumPy arrays
- shape / ndim / size
- indexing and slicing
- mean, median, standard deviation
- min / max
- unique and argmax
- matrix multiplication with `@`
- basic Matplotlib plotting

## Run

Open:

`notebooks/numpy_mini_student_performance.ipynb`

Install the requirements if needed:

```bash
pip install -r requirements.txt
```

Then run the notebook from top to bottom.

## Purpose

This is a learning project, not a production ML project. The goal is to understand what basic NumPy operations actually do before using them inside larger machine-learning workflows.
